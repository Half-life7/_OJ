# Internal integration contract

Module `oj`. JSON field names snake_case. All packages use context-aware methods. Go main never executes user code. Agents own separate directories; coordinate interface changes.

model.Problem: ID int64; Title,Difficulty,Description,InputFormat,OutputFormat,Hint,Checker string; FloatEps float64; TimeLimitMS,MemoryLimitMB int64; IsPublic bool; CreatedBy,SubmitCount,AcceptedCount int64; CreatedAt,UpdatedAt,Status string; Tags []string; Testcases []Testcase; Templates map[string]string; LangLimits map[string]Limits; Solutions []Solution; EffectiveLimits map[string]Limits.
model.Testcase: Index int, Input,Expected,Explanation string, IsSample bool.
model.Limits: TimeLimitMS,MemoryLimitMB int64 (zero means inherit).
model.Solution: Language,Code string.
model.CaseResult: Index int; Status string; TimeUs,TimeMS,MemoryKB int64; IsSample bool; Input,Expected,Actual string (omitempty).
model.Submission: ID,ProblemID,UserID int64; ProblemTitle,Language,Code,Status,Message,CreatedAt,JudgedAt string; TimeUs,TimeMS,MemoryKB int64; Passed,Total int; CaseResults []CaseResult.
